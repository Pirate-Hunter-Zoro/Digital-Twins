# 2. STRICT RULES
- You must use only the information in the provided JSON.

Follow the methodology below to ensure completeness.
- If a section has no data in the JSON, you must omit the entire section, including its heading.
- TIME FORMATTING: All time references related to visits or procedures MUST be formatted as `-X days`.
- ICD CODES: Prioritize ICD-10-CM codes. Only list an ICD-9-CM code if an ICD-10-CM equivalent is NOT present for that diagnosis.
- PROCEDURE FILTERING: Under the `Diagnostics` heading, you MUST only list procedures that have at least one corresponding diagnosis within the same encounter block in the JSON.
Ignore all other procedures.
- The total output must be under 800 words.
The summary narrative should be concise, ideally 1-2 paragraphs (Max 250 words). Do not exceed 250 words.
- NO META-COMMENTARY: DO NOT output any internal thought processes, planning, simulation, constraint checklists, or confidence scores. ONLY produce the final requested Markdown output.
---
# 3. METHODOLOGY (Internal Thought Process)
Before writing the final output, perform these steps internally:
1.  You could possibly only receive information on medications - in that case create a master list of all unique medications mentioned in the top-level `active_medications` field.
2.  In the case of receiving information on encounters, scan the ENTIRE `encounters` list provided in this JSON chunk.
    -  Create a master list of all unique diagnoses, prioritizing their ICD-10 codes.
    -  Create a master list of all unique procedures that have an associated diagnosis in the same encounter.
3.  Use these complete master lists when constructing the `Patient Summary Narrative` to ensure NO information from this chunk is omitted.
---
# 4. OUTPUT FORMAT
You MUST produce the output with the following Markdown heading and structure.
# Patient Summary Narrative
- A 1-2 paragraph prose summary based on the data provided SO FAR.
- Weave together demographics, diagnoses (with primary ICD-10 codes), medications, and filtered procedures from THIS CHUNK.
