DECISIONS MADE THIS SESSION (2026-04-20):
------------------------------------------
- [x] BUG DISCOVERED ON SHAKEDOWN RUN (now MOOT):
        * retriever.py:141 raised UnboundLocalError: normalized_vector during
          deterministic-source neighborhood construction.
        * Root cause: missing vitals (bmi/bp_sys/bp_dias) stored as np.nan in
          the deterministic vector. np.linalg.norm of a NaN-containing array
          returns NaN. `if mag > 0:` evaluates False when mag is NaN, so
          normalized_vector is never bound, and the next line references an
          undefined local.
        * Resolution: the deterministic KNN path is being deleted entirely
          (see next item). No retriever code fix needed.

- [x] DROP KNN RETRIEVAL ON DETERMINISTIC VECTORS.
        Cosine / Euclidean distance on a vector mixing unscaled counts, 0/1
        flags, and one-hot demographics is clinically meaningless — numeric
        columns dominate the norm, binary columns contribute trivially.
        The 2x2 evaluation matrix becomes asymmetric:
          * Classical ML: deterministic AND embedding
          * Neighbor-weighted KNN: embedding ONLY
        VectorSource.DETERMINISTIC is stripped from Retriever, TRDPredictor,
        run_neighborhood_constructor, analyze_trd_prediction, and all four
        analysis scripts. Classical ML retains both sources.

- [x] REFACTOR DETERMINISTIC VECTORS TO TYPED PANDAS DATAFRAME.
        1. Output: single parquet file keyed by patient_id. Retire per-patient
           .npy files. Retire patient_attributes.json.
        2. Column schema by dtype:
             - float64: quantitative features (counts, days, vitals, ages,
               adequate-trial counts)
             - bool:    single-valued binary flags AND multi-label set
               indicators (psych_/medical_/safety_/sud_/sdoh_)
             - category: single-valued nominal fields (Sex, PreferredLanguage,
               MaritalStatus, Religion, SmokingStatus, Race_Ethnicity,
               mdd_recurrence, mdd_severity). Sex becomes ONE column, killing
               the Sex_Male/Sex_Female redundancy.
        3. Preprocessing: single sklearn ColumnTransformer, dtype-routed via
           make_column_selector:
             - numeric:  SimpleImputer(median) -> StandardScaler
             - category: OneHotEncoder(drop='if_binary',
                         handle_unknown='ignore')
             - bool:     passthrough (cast to int8)
        4. XGBoost goes through the same ColumnTransformer output as the
           others — no native enable_categorical branch this iteration.
        5. Missing vitals stay np.nan in the DataFrame. Imputation happens
           inside the pipeline, train-only, preventing the test-set leakage
           the current vector-stage imputation would introduce.
        6. Naive Bayes splits into two lineup entries:
             - GaussianNB  — numeric subset only (dtype_include='number')
             - BernoulliNB — bool + one-hot subset only
                             (dtype_include=['bool','category'])
           Classifier lineup grows from 6 to 7.
        7. Categorical levels discovered in a one-shot JSON-scan pass at
           generator init, cached to categorical_levels.json (much smaller
           than patient_attributes.json).
