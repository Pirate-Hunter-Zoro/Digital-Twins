- [ ] somatic_flag massively over-counts ECT. boolean_summary.csv:
      15.1% prevalence, and it runs BACKWARDS by outcome (15.6% non-TRD
      vs 10.5% TRD) — both impossible for ECT, which is rare and should
      be MORE common in treatment-resistant patients. Root cause:
      scripts/data_loading/procedure_definitions.py ECT_KEYWORDS =
      {"ELECTROCONVULSIVE", "ECT "} matched as a bare substring in
      somatic_treatment_flag (features.py:208). "ECT " matches the tail
      of ordinary procedure words — DEFECT, ASPECT, INSPECT, DISSECT,
      RESECT, TRANSECT — none related to depression, which is exactly
      why the flag is flat/inverted across TRD. Fix: match on word
      boundaries or on actual ECT procedure codes, not a substring.
      SECONDARY: the same function also fires on TMS_KEYWORDS, so the
      feature is really "ECT or TMS" while every display label
      (feature_display_names.py; the narrative "Somatic treatments"
      line) says ECT only — rename or split the feature. ABLATION
      IMPACT: the SAFETY / treatment_contraindications narrative section
      carries somatic content, so permute_treatment_contraindications
      and any somatic-bearing spec produce contaminated deltas until
      this is fixed and embeddings are regenerated.
